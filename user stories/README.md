# User stories

I keep a short list of work I need to follow up on. I can sign in to create tasks and return later to edit, complete, or delete them. My tasks are private to my account.

Use the owning story as the source of truth for each HTTP contract. Add or revise its acceptance criteria and contract before implementing the slice.

| Story | Scope |
| --- | --- |
| [Create a task and see it in my list](create-and-list-tasks.md) | First reference slice |
| [Sign in to my account](sign-in.md) | Sign in with a seeded or registered account |
| [Register an account](register-an-account.md) | Create a new account |
| [Update a task](update-a-task.md) | Edit task details or mark it complete |
| [Delete a task](delete-a-task.md) | Remove a task from the list |
| [Check service health](service-health.md) | Public API verification |
